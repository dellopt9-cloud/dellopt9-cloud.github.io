Privacy Policy: Clips Kitty Uploader

Last updated: November 18, 2026

What this app is

Clips Kitty Uploader is a personal tool used only by its owner to upload video clips to the owner's own YouTube channel from the Clips Kitty desktop app.

Google and YouTube data it uses

When signed in, the app uses the YouTube Data API to upload videos the owner selects and to set their titles, descriptions and privacy settings. It does not read, collect or store any other Google account data.

Where data is kept

Sign-in tokens and API credentials stay on the owner's own computer, stored encrypted by Windows. Nothing is sent to any server other than Google's own APIs. No data is sold, shared or used for advertising.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.

This app uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
